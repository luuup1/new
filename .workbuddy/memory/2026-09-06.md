## 关键设计说明（TD3 连续动作 → 离散动作桥接）
- 不用 DDQN/SAC 的「因子化 Q」（Q(a)=Σ q_bit[i]·bit[i]，link/slot 强耦合下失效）
- TD3 用连续松弛：critic 吃连续概率向量，保持端到端可微，避开因子化假设

## ✅ 关键突破：SAC dimred 修复成功（策略降维 + 完整 critic）
- **根因定位**：之前 SAC/DDQN dimred 用「因子化 Q」Q(a)=Σ q_bit[i]·bit[i] 强制 Q 是 7 bit 的线性组合，link/slot 强耦合下失效 → 全卡 1.0。TD3 用 sigmoid 连续松弛也隐含 bit 独立性假设 → 同样学不动。
- **正解**：actor 保持 7 维 Bernoulli（降维卖点保留），critic 输出完整 96 维 cell Q（价值函数无损）。7 位概率诱导 96 cell 分布：π(c|s) ∝ Π p_i^{b_i(c)}(1-p_i)^{1-b_i(c)}，mask 无效 cell 后 softmax 归一化。buffer 统一存 cell index(int)，critic gather 与 native 完全一致。
- **代码改动**（`tsn_sim/sac.py`）：
  - `__init__` 新增 `n_cells`(dimred=96)/`n_links`/`n_slots` 参数；预计算 `_cell_bits`(96×7) canonical 编码矩阵（与 env._cell_to_bits 对齐，已测一致）
  - `select_action` dimred 分支：7 bit 概率 → 96 cell 分布 → mask(-1e9 避免 NaN) → 采样/argmax cell → 返回 int
  - 新增 `cell_to_bits(cell)` 方法：训练循环喂 env.step 前把 cell 转 7 bits
  - 重写 `_update_dimred`：critic 96 维，标准离散 SAC 公式，π(c|s) 用乘积诱导分布替代 masked softmax
  - 删除旧 `_bits_logprob`/`_all_combos` helper
- **`train_sac.py`**：训练循环/evaluate 改为 select_action 返回 cell index，buffer 存 cell，env.step 前 cell_to_bits 转 7 bits
- **⚠️ NaN 坑**：终止态 next_mask 全 False 时，用 -inf 进 log_softmax 会产生 NaN；改用 -1e9 有限值解决
- **短训结果（seed42, 600ep, simple, CPU, γ=0.5）**：
  - native: best_eval_eff_peak = **0.9487**（ep290 起跌破 1.0，尾段 0.95~0.98 震荡）
  - dimred: best_eval_eff_peak = **0.9444**（ep340 起跌破 1.0，尾段 0.944~0.98，末 ep600=0.9545）
  - **结论：dimred 不再卡 1.0，且追近 native（0.9444 vs 0.9487，仅差 0.004）** —— 证明「价值函数被降维」才是真正根因，策略降维+完整 critic 是正确方向
  - 注意：600ep 短训两者都还没到历史 SAC native 0.68 的水平，需加长训练（2000ep）验证 dimred 能否真正追平/逼近
- **结果图**：`sac_dimred_fix_ab.png`（native vs dimred 收敛对比，含 random/urgency/MILP 参考线）
- **待办**：SAC dimred 加长到 2000ep 正式训练（3 seed），确认能否稳定逼近 native 0.68；TD3 是否也改用「策略降维+完整 critic」思路重写（当前 TD3 连续松弛仍弱）
