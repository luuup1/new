# 2026-07-22 文献研读笔记

## 已读文献
- 标题：A 5G-TSN joint resource scheduling algorithm based on optimized deep reinforcement learning model for industrial networks
- 期刊：Ad Hoc Networks 170 (2025) 103783
- 作者：Yang Zhang, Lei Sun, Zhangchao Ma, Jianquan Wang, Meixia Fu, Jinoo Joung

## 核心模型
- **ME-DDPG**：在 DDPG 基础上嵌入 MCS-based priority scheme，把连续 RB 分配动作降维为 0/1 二值动作（是否调度该流），再用低复杂度优先级启发式完成具体 RB 数量分配。
- **状态**：`S = {RBexp, L, Dnor, G}`，分别为每队列所需 RB 数、队列包数、归一化排队时延、GCL 门状态。
- **动作**：`A = {pi}`，对每个流输出是否调度（M+N 维 0/1 向量）。
- **奖励函数**：分段设计，对时间触发流 Ft 根据 `(dqos - di - dGCL)` 给正/负奖励；对视频流 Fv 根据吞吐量阈值 `thi` 与 `thmin` 关系奖励；并通过 φi 因子放大或缩小奖励幅度。
- **调度流程（每 TTI 三步）**：
  1. Agent 收集 GCL 状态、gNB 队列状态、CQI；
  2. DDPG 输出二值调度决策；
  3. 按 MCS 优先级把可用 RB 分给 urgent Ft → Fv（按 MCS 降序）→ non-urgent Ft。

## 实验要点
- **参数**：500 episodes × 500 TTIs；时间触发流包 50 Bytes，视频流 1000 Bytes；gNB 发射功率 20 dBm；噪声 -90 dBm；子载波间隔 15 kHz → TTI=1 ms；CQI 映射到 3 档 MCS（QPSK/16-QAM/64-QAM）。
- **GCL 配置**：0101（每 TTI 交替）、0011（每 2 TTI 切换）、random（ON 概率 0.5）。
- **用户配比**：6 组，从 |Ft|:|Fv|=2:7 到 12:12，随时间触发流比例增加。
- **对比算法**：O-DDPG（原始 DDPG）、DPF（延迟比例公平）。
- **评估维度**：奖励收敛与稳定性、时延、可靠性（di ≤ dqos 比例）、吞吐量。
- **关键结果**：
  - ME-DDPG 平均奖励、收敛速度、稳定奖励均优于 O-DDPG；
  - 可靠性达 100%（所有场景/episode）；
  - 与 O-DDPG 相比整体吞吐量提升至少 9.16%，最高 10.84%；
  - 在不同 GCL 配置下表现稳定。

## 可借鉴点
1. **动作空间降维**：用 DRL 做 0/1 决策，再靠领域规则（MCS 优先级）做具体资源分配，可显著降低动作空间。
2. **奖励函数分段**：对不同类型流采用不同奖励项，并引入 `dGCL` 惩罚、阈值判断和放大因子 φi，训练更稳定。
3. **CQI→MCS→bytes/RB 映射**：用查表法把无线信道状态纳入吞吐量和 RB 需求计算，简化了环境建模。
4. **实验设计**：固定随机种子、统一包生成、多用户配比、多 GCL 配置，结果更有说服力。
