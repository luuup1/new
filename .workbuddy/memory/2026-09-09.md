# 2026-09-09 工作日志

## SAC dimred 重训（用「策略降维+完整96维critic」修复版）

### 背景
- 负载对比图显示 SAC dimred 劣化（1.040 vs native 0.681），根因是 `11_dimred_max_load.json` 里的 SAC dimred 是旧版（因子化 Q，学不动卡 1.0）。
- 用户要求「SAC 的重训一下」。

### 验证
- 冒烟测试（200ep seed42）：修复版 SAC dimred 从 eval=1.0032 单调降到 1.0000，熵 H≈1.59 稳定、Q 值平稳、无 NaN → 修复代码工作正常，不再卡 1.04。
- 确认 env 约定：native n_actions=96、dimred n_actions=7、obs_dim=199；dimred 模式 `env.action_masks()` 返回 96 维 cell mask。

### 重训配置（对齐 native 口径）
- 命令：`RL/bin/python train_sac.py --episodes 800 --action-mode dimred --period-mode simple --order-mode random --reward-mode load_balance --gamma 0.5 --seed {42,123,2024} --save-dir checkpoints_sac_dimred_fixed_seed*`
- 三 seed 并行跑，seed123 首次进程中断（450ep 处句柄丢失），单独补跑完成。

### 结果（best eval_eff_peak）
| seed | best | 达到轮数 |
|------|------|---------|
| 42   | 0.9545 | ep450 |
| 123  | 0.9286 | ep250 |
| 2024 | 0.9545 | ep500 |
- **均值 0.9459±0.0150**（vs 旧版 1.0397，大幅改善，但仍未追上 native 0.681）。
- 结论：修复版 SAC dimred 从「卡 1.0 学不动」变为「稳定降到 0.93~0.95」，但仍明显劣于 native（0.681），说明 SAC 的 7-bit 乘积诱导分布在 50 流场景下仍损失了有效表达能力，降维对 SAC 有代价。
