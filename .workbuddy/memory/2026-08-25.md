## ⚠️ 关键发现（重要，需用户决策）
dimred seed42 早停过早且结果远差于 native：
| 算法 | dimred best (ep) | native best (ep) |
|---|---|---|
| PPO | 1.0095 (ep50, 早停@300) | 0.9545 (ep1950, 满2000) |
| SAC | 1.0601 (ep100, 早停@350) | 0.6111 (ep250, 满2000) |
| DDQN | 1.0570 (ep50, 早停@300) | 0.6111 (ep1100, 满1332) |

dimred 三算法全部"越训越差"，best 都出现在早期（50-100ep），之后 eff_peak 一路升到 ~1.0+。
根因分析（待验证）：
1. dimred 动作空间 7 bits 只有 128 种组合，且 `_project_to_valid` 把非法 bits 投影到"最近合法 cell"，导致大量不同 bits 映射到同一 cell，动作冗余/退化；
2. 因子化 Q（Σ q_bit[i]*bit[i]）假设各 bit 独立贡献 Q，但 link 位和 slot 位对 Q 的贡献高度耦合，分解假设不成立 → Q 学习信号扭曲；
3. PPO dimred 的 critic valL 高达 ~9000（native 收敛时 ~几百），说明 dimred 下 critic 也学崩。
这直接威胁"降维是创新点"的立意——当前 dimred 实现不仅没提升，反而明显更差。
